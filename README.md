# ローリングバレーボール作戦ボード

ブラウザで選手とボールを動かせる、作戦検討用のボードです。HTML / CSS / JavaScript のみで動き、ビルドや外部ライブラリは不要です。

## 使い方

`index.html` をブラウザで開いてください。

- コートは全体9m×18m、片面9m×9mの比率です。アタックラインはセンターラインから両側3mの位置にあります。
- コート上部の「縦」「横」で向きを切り替えます。縦では下が味方、横では左が味方です。配置と矢印も一緒に向きが変わります。
- 選手は自陣内のみ移動できます。ボールと矢印は両コートをまたげます。以前保存した配置の選手が相手側にいる場合は、自陣側に補正します。
- 味方6人とボールを、マウスまたはタッチでドラッグできます。
- 相手チーム6人は常に表示します。
- 選手・ボール以外の場所をドラッグすると線を描けます。
- 「元に戻す」「やり直す」に対応。Ctrl / Command + Z、Shift + Ctrl / Command + Z も使えます。
- 選手にキーボードでフォーカスすると、矢印キーで位置を微調整できます。
- ツールの①〜⑤を約0.65秒長押しすると、両チームの選手とボールの現在位置を登録します。クリック・タップで呼び出します。キーボードでもSpace / Enterの長押しで登録、短押しで呼び出せます。登録済みのボタンは緑色になります。
- 保存枠は同じブラウザ・同じURLに5件。長押しで上書きします。以前の1件の保存データは①から呼び出せます。ブラウザのデータ消去で保存内容も消えます。
- 「矢印を消す」「初期位置に戻す」は画面上部にあります。

## GitHub Pages

このフォルダーの `index.html`、`styles.css`、`app.js`、`ball.svg`、`manifest.webmanifest`、`sw.js`、`icons/` をそのまま配信できます。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で対象ブランチのルートフォルダーを選択します。

## 選手と線の操作

- 各チームがネットに向いた視点で、右後ろ1・中後ろ2・左後ろ3、右前4・中前5・左前6です。
- 1〜3番はアタックラインの後方、4〜6番はネットとアタックラインの間のみ移動できます。
- 選手とボールをドラッグすると移動し、それ以外の場所では線を描きます。
- ツールの「線の表示」で、これから描く線を「5秒後に消す」（初期設定）または「残す」に切り替えます。5秒は指・マウスを離してから数えます。
- 一時的な線は保存・元に戻すの対象外です。配置枠はプレーヤーとボールの位置のみ保存し、呼び出しても現在の線は変わりません。

## ドラッグ中の狙い表示

ボールのドラッグ中と、離してから5秒間、反対側のアタックラインから奥へ向かう範囲を黄色の半透明で表示します。相手選手の円と、その選手に遮られる方向には色を塗りません。ボールがセンターラインを越えると対象チームが切り替わり、指・マウスを離して5秒後に表示が消えます。ツールの「狙える範囲」で「常に表示する」も選べます。選手の表示サイズを遮蔽物として計算した、直線的な狙いの目安です。

## PWA・オフライン利用

HTTPS（GitHub Pagesなど）またはlocalhostで配信するとPWAとして利用できます。ブラウザのインストール機能、またはiPhone / iPadの共有メニューの「ホーム画面に追加」で登録してください。初回オンライン読み込みとキャッシュ保存が完了すると、オフラインでも起動・操作・配置保存ができます。ファイルを直接開く場合はPWA機能は動きません。

更新を公開する際は `sw.js` のキャッシュバージョンを増やしてください。更新は開いているアプリの画面をすべて閉じた後、次の起動から適用されます。

## 動作確認

Node.jsで `node --test aim.test.cjs` を実行できます。ブラウザ操作の検証はPlaywrightとMicrosoft Edgeを用意して `node --test browser.test.cjs` を実行します。5枠の登録・呼び出し、取消、キーボード操作、画面サイズへの追従、オフライン起動を確認します。

## 標準の作戦とマルチタッチ

①は基本配置、②・③は作戦Aとその左右反転、④・⑤は作戦Bとその左右反転です。反転するのは味方選手とボールです。既存の登録内容は保持し、未登録の枠に標準配置を表示します。ツールの「初期値に戻す」は①〜⑤を標準配置へ戻します（現在のボードは変わりません）。

複数の指で異なる選手・ボールを同時にドラッグしたり、複数の線を同時に描けます。一連の同時操作は、全ての指を離した後にまとめて元に戻せます。操作中断時は中断された指の移動だけを取り消します。

# ローリングバレーボール作戦ボード

ブラウザで選手とボールを動かせる、作戦検討用のボードです。HTML / CSS / JavaScript のみで動き、ビルドや外部ライブラリは不要です。

## 使い方

`index.html` をブラウザで開いてください。

- コートは全体9m×18m、片面9m×9mの比率です。アタックラインはセンターラインから両側3mの位置にあります。
- コート上部の「縦」「横」で向きを切り替えます。縦では下が味方、横では左が味方です。配置と矢印も一緒に向きが変わります。
- 選手は自陣内のみ移動できます。ボールと矢印は両コートをまたげます。以前保存した配置の選手が相手側にいる場合は、自陣側に補正します。
- 味方6人とボールを、マウスまたはタッチでドラッグできます。
- 相手チーム6人は常に表示します。
- 選手・ボール以外の場所をドラッグすると線を描けます。
- 「元に戻す」「やり直す」に対応。Ctrl / Command + Z、Shift + Ctrl / Command + Z も使えます。
- 選手にキーボードでフォーカスすると、矢印キーで位置を微調整できます。
- 保存は同じブラウザ・同じURLに1件。再度「配置を保存」を押すと上書きします。ブラウザのデータ消去で保存内容も消えます。

## GitHub Pages

このフォルダーの `index.html`、`styles.css`、`app.js`、`ball.svg` をそのまま配信できます。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で対象ブランチのルートフォルダーを選択します。

## 選手と線の操作

- 各チームがネットに向いた視点で、右後ろ1・中後ろ2・左後ろ3、右前4・中前5・左前6です。
- 1〜3番はアタックラインの後方、4〜6番はネットとアタックラインの間のみ移動できます。
- 選手とボールをドラッグすると移動し、それ以外の場所では線を描きます。
- ツールの「線の表示」で、これから描く線を「5秒後に消す」（初期設定）または「残す」に切り替えます。5秒は指・マウスを離してから数えます。
- 一時的な線は保存・元に戻すの対象外です。「残す」で描いた線は配置と一緒に保存できます。

## ドラッグ中の狙い表示

ボールのドラッグ中と、離してから5秒間、反対側のアタックラインから奥へ向かう範囲を黄色の半透明で表示します。相手選手の円と、その選手に遮られる方向には色を塗りません。ボールがセンターラインを越えると対象チームが切り替わり、指・マウスを離して5秒後に表示が消えます。ツールの「狙える範囲」で「常に表示する」も選べます。選手の表示サイズを遮蔽物として計算した、直線的な狙いの目安です。

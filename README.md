# ローリングバレーボール作戦ボード

ブラウザ上で両チームの選手とボールを動かし、配置や狙いを検討する作戦ボードです。マウス・タッチ・キーボードに対応しています。HTML / CSS / JavaScriptで動作し、アプリの実行にビルドや外部ライブラリは不要です。

## 起動と初期表示

- `index.html` をブラウザで開くと利用できます。PWA・オフライン機能を使う場合はHTTPSまたはlocalhostで配信します。
- 初回表示はブラウザの表示領域が横長なら横、縦長または正方形なら縦になります。起動・再読み込み時は長辺合わせでコート全体を表示します。
- 縦表示は下が味方、横表示は左が味方です。縦横切替時は短辺合わせ（100%）に戻り、縦なら最下部、横なら左端を表示し、自コートから操作できます。
- 起動時の配置は基本配置です。保存枠を自動で呼び出すことはありません。
- 再読み込みすると、現在の配置・矢印・履歴・表示設定・拡大率は初期状態に戻ります。登録済みの配置枠は残ります。

## 画面と操作ボタン

上部はスマホでも高さ48pxの1段表示です。コートをスクロールしても操作部は固定表示されます。

| 場所・ボタン     | 動作                                                             |
| ---------------- | ---------------------------------------------------------------- |
| 左上のRVアイコン | アプリ自身のURL（`./`）へのリンク                                |
| ☰               | ツールパネルを開く・閉じる                                       |
| 自動位置OFF / ON / FULL | タップで3段階切替。ONは反対側の中4人、FULLは6人を自動配置。起動時はOFF |
| 矢印消去         | 表示中の矢印をすべて消す（残す線・一時的な線の両方）             |
| 初期位置へ       | 最後に呼び出した配置の最新内容へ戻し、矢印も消す。未呼び出し時は基本配置へ戻る |
| ↶ / ↷            | 元に戻す / やり直す。実行できない場合は無効表示                  |

ツール内にはアプリケーションタイトル、「ⓘ 使い方」、コートの向き、線の表示、狙える範囲、配置と作戦の①〜⑤、登録枠の「初期値に戻す」があります。

ツールは☰の再タップ、パネル外のタップ、Escapeキーで閉じます。パネル外のコートへの最初のタップはパネルを閉じるだけで、選手移動や描画は開始しません。上部操作ボタンはパネルを閉じながら実行できます。パネルが画面に収まらない場合はパネル内をスクロールできます。

## 使い方の表示

ツール内のアプリタイトル直下にある「ⓘ 使い方」で操作説明を開きます。自動表示はしません。背景を暗くした中央の説明カードが表示され、スマホでは画面幅に合わせて説明部分だけをスクロールできます。右上の「× 閉じる」は常に表示され、閉じると元のツール画面に戻ります。説明カード外の暗い背景のタップやEscapeでも閉じられます。表示中は背景の操作を受け付けません。タッチ操作では指を離した時点でも開く判定を行い、クリックイベントへの依存を避けています。説明本文のタップやスクロールでは閉じません。説明内から背景へ指を滑らせただけでは閉じず、背景を押して離した場合に閉じます。閉じた後は「ⓘ 使い方」にフォーカスが戻ります。再度開くと説明の先頭を表示します。

基本操作は選手・ボール移動、矢印描画、コート表示、配置保存・呼び出し、履歴、初期化の6項目です。「その他の操作」を開くと縦横切替、狙える範囲、マウス・キーボード操作を確認できます。

## コートと表示サイズ

- コートは9m×18m、片面9m×9mの比率です。アタックラインはネットから両側3mの位置にあります。
- 味方6人（青）、相手6人（赤）、ボール1個を常に表示します。
- プレーヤーの円は自動位置OFFでは、コート縮尺に対して前衛（4〜6番）は直径75cm、後衛（1〜3番）は直径100cmです。ON・FULLではボールとの中心間距離に応じて直径が最大125cmまで変わります。番号の文字サイズと枠線も円に比例します。
- 選手の円は、相手のアタックに対するレシーブ可能範囲の目安です。相手に近い前衛は両ひざの横あたりまで、後衛はもう少し手を広げて対応できるため、円の大きさを変えています。
- ボールは操作しやすいよう、実物より大きい直径50cm相当で表示します。
- 縦横切替・画面サイズ変更・拡大縮小でも、プレーヤーとボールの縮尺および大きさの比率を維持します。

## 表示方向・スクロール・拡大縮小

- ツール内の「縦」「横」で手動切替できます。選手・ボール・矢印も一緒に向きが変わります。
- 自動で向きを選ぶのは起動時です。その後の画面サイズ変更では現在の向きを維持します。
- 100%表示は短辺に合わせます。縦なら表示領域の幅、横なら操作部を除いた表示領域の高さが基準です。
- 収まらない部分はスクロールで表示できます。拡大時は短辺側も含め、縦横にスクロールできます。スクロールバーの見え方はブラウザ・OSの設定に従います。
- スクロール可能な表示では、空いているコートを長押しせずに1本指で動かすとパン（スクロール）します。2本指以上を一緒に動かしてもパンでき、指の間隔を広げる・狭めると拡大縮小します。指の間を中心に拡大縮小します。
- 拡大率の下限はコート全体が表示領域に収まる長辺合わせのサイズです。上限は短辺合わせを100%とした300%です。
- プレーヤー・ボールのないコートをダブルタップすると、長辺合わせ（全体表示）と短辺合わせ（100%）を切り替えます。全体表示付近なら短辺合わせ、それ以外の拡大率なら全体表示に切り替わります。マウスのダブルクリックでも操作できます。タッチ時は24pxまでの指の揺れをパン開始とみなさず、各タップ500ms未満・1回目を離してから2回目を押すまで450ms未満・位置差40px未満を目安に判定します。
- ダブルタップでサイズを切り替えた後は、縦なら最下部、横なら左端の自コート側を表示します。プレーヤー・ボール上のタップやドラッグ、複数指操作はダブルタップ切替の対象外です。
- 「縦」「横」を選ぶと拡大率は100%に戻ります。現在と同じ向きのボタンでも100%に戻せます。

## 選手・ボールとマルチタッチ

- 両チームの選手・ボールをマウスまたは指でドラッグできます。相手と味方の選手を同時に動かすこともできます。
- 選手はドラッグ中は自由に動き、離すと240msのアニメーションで25cm間隔のグリッドへそろいます。センターライン・アタックラインに接する位置も停止位置に含み、ラインの太さは計算に含めません。ボールの移動はグリッドの対象外です。
- 基本配置の番号は各チームがネットに向いた視点で、右後ろ1・中後ろ2・左後ろ3、右前4・中前5・左前6です。
- 指を離した際は、1〜3番は自陣のアタックライン後方、4〜6番は自陣のネットとアタックラインの間に位置を補正します。保存配置の呼び出し時も範囲内に補正します。
- ボールは両コートを移動できます。選手・ボールの中心はコートの境界内に制限されます。
- 同じ駒を複数の指で同時につかんだ場合、先に触れた指の操作を優先します。
- 矢印がないときは、コートの空いている部分を約0.5秒長押しした後に動かすと矢印描画になります。矢印が1本以上あれば、次からは長押しせずに描画できます。すべての矢印が消えると、再び長押しが必要です。長押し前に動かすと1本指でパン、2本指以上でパン・拡大縮小です。選手・ボールを操作する指は、この本数に含めません。
- コート上の2本目の指が触れると描画途中の矢印を取り消します。残った1本指ではパンを続けられます。描画は再開せず、コート操作の指を離してから改めて描画します。
- 一方の指を離しても、別の指での選手・ボール操作は継続できます。操作中断時は中断した指による移動だけを取り消します。
- コートのドラッグ中は、配置の保存・呼び出し、元に戻す・やり直す、縦横切替など、配置を置き換える操作は実行しません。

## 自動位置

- 上部のボタンはタップするたびに「自動位置OFF → 自動位置ON → 自動位置FULL → 自動位置OFF」と切り替わります。起動・再読み込み時はOFFです。モードの切替だけでは選手の中心位置を動かしません。
- ON：ボールの反対側のチームで、左右のサイドラインに最も近い選手を1人ずつ固定し、中4人を自動配置します。前衛・後衛は問いません。同距離なら現在の固定メンバー、前衛、番号順を優先します。
- FULL：サイドライン側の選手も含めて、ボールの反対側の6人全員を自動配置します。固定メンバーはありません。
- ボールをドラッグまたは矢印キーで動かしたときだけ自動配置します。ネットを越えると対象チームが切り替わります。
- ON・FULLでも両チームの全選手を手動移動できます。手動移動完了・25cm単位への補正後に固定メンバーを選び直します（固定対象を使うのはON時だけです）。同じチームを複数の指で操作している場合は全員の操作完了後に選び直します。
- ONではサイドラインに最も近い位置へ動かした選手が固定対象になります。自動配置対象の手動配置は次のボール移動で更新されます。手動配置を維持したままボールを動かす場合はOFFにしてください。
- 選手とボールは同時にタッチ操作できます。選手を1人でもつかんでいる間は自動配置と移動アニメーションを一時停止します。全選手を離しただけでは再開せず、その後の次のボール移動から再開します。
- アニメーション中の選手をつかむと、見えている位置から手動操作を引き継ぎます。指を離すと25cm単位（ライン付近では接触位置）へ補正します。
- 自動配置の前後位置は、拡大後の円がアタックラインに接する位置です。前衛はネット側、後衛はエンドライン側に、直径の半分だけ中心を離します。
- 左右は25cm刻みの候補から、ボールから見た最大の隙間、空いた方向の合計、隙間の偏りを順に減らす配置を探します。同程度なら移動量を減らします。ONでは固定メンバーの内側、FULLではコート幅全体を使い、同じ列の追い越しと円の重なりを避けます。
- 左右の入れ替えを抑えるため、現在の左右位置を保った配置の「狙える隙間の合計」が、探索で選んだ最適候補より10%以内の増加なら、左右位置を維持します（ON・FULL共通）。前後は円の大きさに合うライン接触位置へ更新します。10%を超える場合、または重なり等で現在の左右位置を維持できない場合は配置を更新します。
- 自動移動は約240〜600msのアニメーションで表示します。ボール移動中に配置先が変わると、表示中の位置から新しい配置先へつながります。ボールを離した後は最後の配置への移動だけ完了します。手動移動後の位置補正は240msです。
- OFFにすると最後に決めた配置で停止します。ボール移動と自動配置はまとめて元に戻せます。ボール操作の中断時はその操作による自動配置も取り消しますが、途中で別の指により手動調整した選手は巻き戻しません。
- 配置呼び出し・「初期位置へ」でOFFになります。モードは配置枠に保存しません。
- 固定した2人が近すぎるなど、条件を満たす配置が見つからない場合は移動を見送り、調整を案内します。

### ON・FULLのプレーヤーサイズ

両チームの全選手（ONの固定メンバーも含む）が対象です。ボール中心と、表示中の選手中心の実距離で直径を決め、ボール・選手の移動中も更新します。ボール自体のサイズは変わりません。

| 中心間距離 | 前衛の直径 | 後衛の直径 |
| --- | --- | --- |
| 3m未満 | 75cm | 1m |
| 3m以上・5m未満 | 1m | 1m |
| 5m以上 | 1.25m | 1.25m |

OFFでは前衛75cm・後衛1mへ戻ります。サイズ変更だけでは固定した中心位置を動かしません。狙える範囲の表示と自動配置の評価にも、その位置での直径を使用します。

## 矢印と狙える範囲

### 矢印

- 矢印がないときは、選手・ボール以外のコートを指またはマウスで約0.5秒長押しし、そのまま動かすと矢印を描きます。矢印が1本以上表示されている間は、次から長押しせずドラッグして描けます。自動消去・手動消去など理由を問わず0本になると、次の描画には再び長押しが必要です。長押し前に動かすと描画せず、表示がはみ出している方向にパンします。ごく短い操作は線として確定せず、次回も長押しが必要です。
- 「線の表示」は「5秒後に消す」（初期設定）と「残す」から選べます。設定はこれから描く線に適用されます。
- 一時的な線は、最後の一時的な矢印を描き終えて指・マウスを離してから5秒後にまとめて消えます。矢印の描画を開始してから終えるまでは、前に描いた一時的な線も消えません。指を止めて考えている間も保持し、描画終了後にすべての一時的な線の待ち時間を5秒に戻します。描かずに離す・操作中断・2本指パンへの切替の場合も、その時点から5秒後に消去します。「残す」で描いた矢印は自動消去しません。一時的な線は配置保存・元に戻すの対象外です。
- 配置枠は選手とボールの位置のみ保存します。呼び出しても現在の矢印は変わりません。

### 狙える範囲

- 初期設定は「ボールを離して5秒後に消す」です。ボールのドラッグ中と、離してから5秒間表示します。「常に表示する」も選べます。
- ボールから反対側のアタックラインを通って奥へ向かう狙いを、黄色の半透明で表示します。
- 相手選手の円と、その選手に遮られる方向は表示対象から除きます。ボールがネットを越えると対象チームが切り替わります。
- 現在のプレーヤーの円を遮蔽物として計算した、直線的な狙いの目安です。

## 配置と作戦：①〜⑤

| 枠  | 標準配置            |
| --- | ------------------- |
| ①   | 基本配置            |
| ②   | 作戦A（下表の座標） |
| ③   | 作戦Aの左右反転     |
| ④   | 作戦B（下表の座標） |
| ⑤   | 作戦Bの左右反転     |

- ②〜⑤は前衛3人・後衛3人それぞれの前後位置を揃えています。
- 相手選手にも自陣側から見て同じ標準配置を適用します。左右反転では両チームとボールを反転します。
- タップ・クリックで、登録された両チームの選手とボールの位置を呼び出します。
- 最後に呼び出した枠は、再読み込みまで「初期位置へ」の戻り先になります。その枠を上書きした場合や「初期値に戻す」で標準配置へ戻した場合は、ボタンを押した時点の最新内容へ戻ります。まだ枠を呼び出していない場合は基本配置へ戻ります。
- 約0.65秒の長押しで、現在の両チームとボールの位置を登録・上書きします。ユーザーが登録した両チームの位置は、そのまま保存・復元します。
- 長押し中は枠を強調表示し、登録完了を通知します。長押し中に指が10pxを超えて動く、操作が中断する、フォーカスが外れる、画面が非表示になる場合は待機中の登録を取り消します。
- 標準配置または保存配置を呼び出せるボタンは緑色です。保存・読み込みに失敗した場合はメッセージを表示します。
- ツール内の「初期値に戻す」は①〜⑤を標準配置へ上書きします。現在表示中のボードは変えません。登録枠の上書きは「元に戻す」の対象外です。
- 既存の登録内容は自動で上書きしません。未登録の枠は標準配置を使います。標準配置の更新を反映する場合は「初期値に戻す」を押してください。

| ------ | ---------- | ------------ | ------------ |
| 味方1  | (72, 82)   | (74.2, 70.5) | (85.4, 70.5) |
| 味方2  | (50, 82)   | (57.8, 70.5) | (57.8, 70.5) |
| 味方3  | (28, 82)   | (31.5, 70.5) | (31.5, 70.5) |
| 味方4  | (72, 57.5) | (85.2, 60.5) | (71.6, 60.5) |
| 味方5  | (50, 57.5) | (47.4, 60.5) | (47.4, 60.5) |
| 味方6  | (28, 57.5) | (21.6, 60.5) | (21.6, 60.5) |
| ボール | (50, 73)   | (65.1, 54.6) | (60.7, 54.6) |

相手の同番号は味方の(x, y)に対して(100−x, 100−y)です。③・⑤はそれぞれ②・④の全駒のxを100−xにします。表示時には選手の移動可能範囲による補正が適用されます。

### 保存先と保持範囲

ブラウザのlocalStorageに5枠を保存します。サーバーや他の端末への同期はありません。同じブラウザの同一オリジン（プロトコル・ホスト・ポート）では保存領域を共有し、別タブでの登録変更も反映します。ブラウザのサイトデータを消去すると保存内容も消えます。

保存キーは `rv-tactic-board-v1-slots` です。旧版の1件保存キー `rv-tactic-board-v1` に有効なデータがあり、新しい保存枠がまだない場合は①として読み込みます。配置データは人数・識別子・座標などを検証してから適用します。

## キーボードと操作履歴

- 選手にフォーカスして矢印キーを押すと画面上の方向へ25cm単位で移動します。ボールは従来どおり微調整できます。
- 配置ボタンにフォーカスし、Space / Enterの短押しで呼び出し、長押しで登録できます。
- Ctrl / Command + Zで元に戻し、Shift + Ctrl / Command + Zでやり直します。
- 履歴は最大60操作です。選手・ボールの移動、残す矢印の描画・消去、配置呼び出し、「初期位置へ」が対象です。新しい操作でやり直し履歴は消えます。
- 一連の同時操作は、全ての操作中の指を離した後にまとめて元に戻せます。
- 表示方向、拡大率、スクロール位置、表示設定、登録枠の上書き、一時的な線は履歴の対象外です。
- ボタン・駒には読み上げ用ラベルとフォーカス表示があり、保存結果などは通知領域でも伝えます。

## PWA・オフライン利用と公開

`index.html`、`styles.css`、`app.js`、`board-model.js`、`ball.svg`、`manifest.webmanifest`、`sw.js`、`icons/` を配信してください。サブディレクトリでの公開にも対応する相対パス構成です。GitHub Pagesで公開する場合は、リポジトリのSettings → Pagesで対象ブランチのルートフォルダーを選択します。

- HTTPSまたはlocalhostでPWAを利用できます。ファイルを直接開く場合はPWA機能は動きません。
- 対応ブラウザのインストール機能やホーム画面追加機能で登録できます。アプリ内専用のインストールボタンはありません。
- インストール名は「ローリングバレーボール作戦ボード」、短縮名は「RV作戦ボード」です。単独ウィンドウ表示と192px・512pxのアイコンを設定しています。
- 初回オンライン読み込みとキャッシュ保存完了後は、オフラインでも起動・操作・配置保存ができます。
- アプリの表示ファイルはキャッシュを優先して読み込みます。更新を公開する際は `sw.js` のキャッシュバージョンを増やしてください。
- 新しい版のダウンロード後、旧版を使用中の画面をすべて閉じると更新が有効になります。次の起動で新しい版を使用します。

## 動作確認

狙い範囲の計算・配置データの検証はNode.jsで実行します。

```sh
node --test aim.test.cjs model.test.cjs auto-position.test.cjs
```

ブラウザテストにはNode.jsから参照可能なPlaywrightパッケージとMicrosoft Edgeが必要です。アプリの実行自体には不要です。

```sh
node --test aim.test.cjs model.test.cjs auto-position.test.cjs browser.test.cjs browser.auto.test.cjs
```

自動位置の計算・固定メンバー選択・ON・FULL計120通りのボール位置と配置・3m/5mのサイズ境界・3段階切替・アニメーション・On中の全選手の手動操作・同時タッチ時の自動停止と再開・アニメーション途中のつかみ直し・固定メンバー交代・ネット越え・操作中断・履歴・縦横表示・320px幅の上部表示も検証します。

## ソースコードの全体構成

アプリはビルド不要の静的ファイル構成です。詳しい責務、処理の流れ、座標系、変更時の確認項目は [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。

| ファイル                                             | 役割                                                            |
| ---------------------------------------------------- | --------------------------------------------------------------- |
| `index.html`                                         | ツール・固定バー・コート・説明ダイアログの構造と使い方          |
| `styles.css`                                         | コートの縦横表示、駒の縮尺、スクロール、各UIの見た目            |
| `board-model.js`                                     | DOMに依存しない初期配置、標準配置、保存データ検証、狙い範囲計算 |
| `app.js`                                             | 状態管理、描画、入力操作、履歴、保存、起動処理                  |
| `sw.js`                                              | オフライン用ファイルの保存と取得、旧キャッシュの整理            |
| `manifest.webmanifest`                               | PWAの名称、起動先、表示方法、アイコン                           |
| `ball.svg`、`icons/`                                 | ボールの絵とアプリアイコン                                      |
| `aim.test.cjs`、`model.test.cjs`、`browser.test.cjs` | 計算・保存形式・ブラウザ操作の回帰テスト                        |
| `.prettierrc.json`                                   | インデントと改行幅などの整形ルール                              |

処理の背景や設計上の制約は日本語コメントで記載しています。整形にはPrettierを使用します（開発時のみ必要）。SVGを整形するときはHTMLパーサーを指定してください。

```sh
npx prettier --write app.js board-model.js sw.js index.html styles.css "*.test.cjs" manifest.webmanifest .prettierrc.json
npx prettier --write ball.svg --parser html
```
